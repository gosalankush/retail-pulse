# Retail-Pulse

A robust, console-based Java inventory management system build with modern maven dependency and a MySQL backend.

## Tech Stack

* **Language:** Java 17/21
* **Database:** MySQL
* **Build Tool:** Apache Maven
* **Architecture:** DAO (Data Access Object) Pattern with JDBC

## Features

* View all products in a formatted console table.
* Add new products with secured prepared statements.
* Update existing product prices and stock quantities by name.
* Delete products from the database cleanly.
